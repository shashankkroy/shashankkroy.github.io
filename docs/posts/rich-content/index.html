Hugo ships with several Built-in Shortcodes for rich content, along with a Privacy Config and a set of Simple Shortcodes that enable static and no-JS versions of various social media embeds.

Images¶

Cheat sheet for this site. Image lookup and processing live in layouts/_default/_markup/render-image.html, layouts/shortcodes/img.html and layouts/partials/image/. The full option list is in the comment at the top of layouts/shortcodes/img.html.

Where to put images¶

Put shared images in assets/images/. Images there can be cropped and resized at build time. Any of these path styles works, from any post:

![alt](fig.png)
![alt](images/fig.png)
![alt](/images/fig.png)
![alt](../images/fig.png)

Lookup order:

  1. the post’s own folder (when the post is a folder with an index.md)
  2. the section folder, e.g. content/posts/images/
  3. assets/ and assets/images/
  4. static/ and static/images/ (served as-is, cannot be cropped or resized; only the CSS display options work)

If an image isn’t found, hugo prints a WARN Image "..." not found line. Check the build output.

Full control: the img shortcode¶

{{< img src="images/CLV1_in_XZfor_truth.png" fill="800x400" anchor="top"
        width="70%" align="center" caption="Covariant Lyapunov vector 1" link="true" >}}

Cropping and resizing (makes a new image file at build time; for images in assets/ or a post’s own folder; pick one):

OptionExampleWhat it does
fillfill="800x400"scale and crop to exactly 800×400 (usually what you want)
cropcrop="800x400"cut an 800×400 region out of the original, no scaling
fitfit="800x400"shrink to fit inside 800×400, keep the aspect ratio
resizeresize="600x", resize="x400"scale to a width and/or height

Order of precedence if several are given: fill > crop > fit > resize.

Modifiers:

OptionValuesNotes
anchorcenter (default), smart, top, bottom, left, right, topleft, topright, bottomleft, bottomrightwhich part survives a fill/crop; smart lets Hugo pick the most detailed area
quality1–100JPEG/WebP quality
rotate90, 180, 270counter-clockwise rotation
formatwebp, png, jpgconvert the output

Display only (CSS, original file untouched; also works for SVGs and static/ images):

OptionExampleWhat it does
width / heightwidth="70%", width="400px"size on the page
ratioratio="16/9", ratio="1/1"crop the visible area to this aspect ratio
positionposition="30% 20%"with ratio: the focus point (x% y%) that stays in view. Use this for a precise crop that anchor can’t express

Other: alt, caption (markdown allowed), title, align (left, center, right), link ("true" opens the original on click, or give a URL), class.

Recipes¶

<!-- Square thumbnail from the top-left corner -->
{{< img src="images/enhanced_L63_attr_12.png" fill="400x400" anchor="topleft" >}}

<!-- Shrink a huge figure so the page loads fast, keep full-res on click -->
{{< img src="images/enhanced_L63_attr_12.png" resize="1200x" link="true" >}}

<!-- Banner crop with an exact focus point (CSS) -->
{{< img src="images/CLV2_in_XZfor_truth.png" resize="1500x" ratio="21/9" position="50% 30%" >}}

<!-- Small right-aligned image with a caption -->
{{< img src="images/schematic.png" fit="300x300" align="right" caption="*Schematic*" >}}
