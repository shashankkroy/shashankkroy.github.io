Why do they care about reproducing kernel Hilbert spaces? And who is 'They?'

A quick intro to reproducing kernel hilbert spaces, their intuition and applications in machine learning.

Alright. I have felt for quite sometime that the mathematical proofs do a great job at proving theorems. However, they don’t necessary bake sufficifient amount of intuition for someone reading them for the first time. This is because most of the times, their technical details are aimed towards perfecting the rigour for mature mathematician community. This unintentionally hide the intuition that guides beginner from accessing the topic. A reason why blogs exist, a format different from academic writing, where the goal is not to exposition but guided intuition, opening it up to a wider audience.

So for the next few minutes, let us sit with our espresso, and think of this as a conversation between you and me that would casually discuss post lunch standing outside a cozy cafeteria.

To begin, we will start from the notions we are already comfortable with. In dimensions beyond 1, vector spaces are our first tools to organize numerical information with certain structure - we can add them, scale them and the resulting objects are still in the same space. In addition, we can define how big a vector is by summing up the contribution from the individual components.

In Physics, a vector space is nothing but a repsentation of the state or configurations. Operations on a vector like addition or scaling represents manipulation of the state or configuration of some physical system if we were to make a connection to the physical world. A person from the CS would say these are objects of the same type can be added or scaled and the resulting object is still of the same type. It is a simple but important property that allows us to organize our information in a structured way.

Ofcouse, we also need to define a notion of norm. Norms allow us to measure the size of the object in the space at a overall level, so we sum up the contributions of each component. Two objects of the same size can vary widely in their configuration, since different sums of squares can result in the same total.

Function Spaces: A infinite-dimensional generalization of vector spaces¶

Now, notice that taking similarity of two configurations is not an answer vector space can provide. How similar two confiurations are means how close these two vectors are in the vector space. If you want to asnwer such questions, we need to define a notion of similarity called inner product.

Inner product are the first step towards thinking about the clusteriong or categorizing of configurations as they measure similarity and dissimilarity between two configurations. The inner product allows us to define angles and lengths in the space, which is crucial for many applications in machine learning and data analysis.

$${f_1(x),f_2(x),…,f_n(x) \rightarrow f(x)} $$

When we say that we have a convergent sequence, does it mean we are talking about the value of the function to match everywhere? There are some notions of convergence that we must discuss before we move ahead.

Hilbert spaces¶

While all things said about finite dimensional spaces hold for any finite n, once you strech too far and take n to infinity, we are in a different world - the world of infinite dimensional function spaces.

Recall from high school that for us, a function means a mapping from one space to another. It allows us to assine a value to each point in the domain. But treating them as vectors for the first time is not a natural picture that comes to our mind. Why should we think of a function which has a different value at each point in the domain as a vector? How are these close by points in the domain similar to the notion of components that we are used to in finite dimensional vector spaces? We must resist.

$$f(x) \to y $$

To complelely define a function, we need to know the value of the function at each point in the domain. A mathematical closed form such as sine, cosine, exponential, etc. is a compact way to represent the function. But in general, we cannot always represent a general function in a closed form. This is sad, so if a function that looks like $sin(x)$ over a small interval, might look very different elsewhere. As you can already guess, this means we either know a closed form for the function or we know it’s value everywhere. A closed form is just a way to evaluate the function which makes life easy. And if all possible functions had a closed form, we would just have a inifintie list of functions - an inifinite list.

Now, I will guide you start treating them like vectors in a minute. Remember vectors could have similar components and dissimilar components? A functions could have a interval over which it agrress to other functions in terms of value, while disagreeing at other intervals. Any finite region or interval only captures a finite part of information about this function. If we measured the two functions on the regions they agree, they will behave exactly similar( a pinch of salt). If you try to define a metric of distance between them which only concerns this region, the metric will give us a zero because the two functions are identical here.

This is wild. How then, do we find our functions in such a weird space? Do we need infinite amount of informations. It turns out that this is not the case is the reason why Mathematicians exist in principle!

Defining objects in the right space, with structures that allow them to constrain our function by contraining how it is being constructed or approximated is at it’s core.
