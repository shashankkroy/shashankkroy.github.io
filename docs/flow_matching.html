Ordinary Differential Equations

The language of continuous motion and flow

What is an ODE?

An ODE describes how a state x evolves over time through a velocity field u. Given an initial condition, the trajectory is entirely deterministic — no randomness involved.

\[\frac{d\mathbf{x}}{dt} = u_t(\mathbf{x}), \quad \mathbf{x}(0) = \mathbf{x}_0\]

The function \(u_t: \mathbb{R}^d \to \mathbb{R}^d\) is the vector field — it assigns a velocity arrow to every point in space at every time \(t \in [0,1]\). Integrating this ODE gives a flow map \(\phi_t\) such that \(\mathbf{x}(t) = \phi_t(\mathbf{x}_0)\).

Why ODEs for generative models?

A flow-based generative model learns a vector field \(u_t\) that transports a simple source distribution \(p_0\) (e.g. Gaussian) to a complex target \(p_1\) (e.g. images). The probability density evolves according to the continuity equation:

\[\frac{\partial p_t}{\partial t} + \nabla \cdot (p_t \, u_t) = 0\]

This guarantees that probability mass is conserved — no particles are created or destroyed, just transported.

From ODEs to SDEs

Adding noise — stochastic differential equations

The stochastic extension

An SDE adds a diffusion term driven by Brownian motion \(W_t\). This injects randomness into the trajectory, allowing exploration of probability distributions rather than following a single deterministic path.

\[d\mathbf{x} = u_t(\mathbf{x})\,dt + \sigma_t\,dW_t\]

Here \(\sigma_t \geq 0\) is the diffusion coefficient. When \(\sigma_t = 0\) we recover the ODE. When \(\sigma_t > 0\), each particle follows a distinct noisy path, yet the ensemble still transports \(p_0 \to p_1\).

Itô vs Stratonovich

The stochastic integral \(\int \sigma_t\,dW_t\) has two common interpretations. For generative modeling, the Itô convention is standard — it's non-anticipatory and satisfies useful martingale properties. The Fokker-Planck equation governs density evolution:

\[\frac{\partial p_t}{\partial t} = -\nabla\cdot(p_t u_t) + \frac{\sigma_t^2}{2}\Delta p_t\]

The Laplacian term \(\frac{\sigma^2}{2}\Delta p_t\) acts as a diffusion operator, smoothing the density over time.

Left: deterministic ODE (σ=0). Right: stochastic SDE (σ>0). Same drift, different realizations.

The Langevin Equation

Sampling from distributions via gradient-guided diffusion

Langevin dynamics

The Langevin SDE is a special case where the drift is the score function — the gradient of the log-density of the target. It drives particles toward high-probability regions while noise prevents collapse.

\[d\mathbf{x} = \nabla \log p(\mathbf{x})\,dt + \sqrt{2}\,dW_t\]

Remarkably, under mild conditions, the stationary distribution of this SDE is exactly \(p(\mathbf{x})\). This is the foundation of score-based generative models (NCSN, DDPM).

Connection to flow matching

Flow matching generalizes this idea: instead of fixing the drift to the score, we learn a time-dependent vector field \(u_t\) that continuously morphs \(p_0\) into \(p_1\). The Langevin SDE corresponds to a specific choice of drift and diffusion that achieves this using the score at each time step.

\[u_t^{\text{Langevin}}(\mathbf{x}) = \nabla \log p_t(\mathbf{x}) \quad (\text{score at time }t)\]

Conditional Distributions

Building blocks of the flow matching objective

The marginal path

Flow matching works by constructing a probability path \(\{p_t\}_{t\in[0,1]}\) interpolating between noise \(p_0 = \mathcal{N}(0,I)\) and data \(p_1 = q(\mathbf{x})\). Rather than designing the marginal path directly, we use conditional paths.

Given a data sample \(\mathbf{x}_1 \sim q\), define a conditional path:

\[p_t(\mathbf{x}\,|\,\mathbf{x}_1) = \mathcal{N}\!\left(\mathbf{x}\,;\,\mu_t(\mathbf{x}_1),\,\sigma_t^2 I\right)\]

The marginal path is recovered by marginalizing: \(p_t(\mathbf{x}) = \int p_t(\mathbf{x}|\mathbf{x}_1)\,q(\mathbf{x}_1)\,d\mathbf{x}_1\).

Gaussian conditional paths

The most common choice is a linear interpolation:

\[\mu_t(\mathbf{x}_1) = t\,\mathbf{x}_1, \qquad \sigma_t = 1 - (1-\sigma_{\min})t\]

At \(t=0\): pure Gaussian noise. At \(t=1\): concentrated near the data point \(\mathbf{x}_1\). The interpolation is smooth and tractable.

Conditional Vector Field

The tractable target for flow matching training

The key insight

Directly computing the marginal vector field \(u_t(\mathbf{x})\) is intractable. But we can compute the conditional vector field \(u_t(\mathbf{x}|\mathbf{x}_1)\) in closed form — it simply points from the current noisy sample toward the data point.

\[u_t(\mathbf{x}\,|\,\mathbf{x}_1) = \frac{\mathbf{x}_1 - (1-\sigma_{\min})\mathbf{x}}{\sigma_t}\]

The Flow Matching loss regresses a neural network \(v_\theta\) onto this conditional target:

\[\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t,\,\mathbf{x}_1\sim q,\,\mathbf{x}\sim p_t(\cdot|\mathbf{x}_1)}\left[\|v_\theta(\mathbf{x},t) - u_t(\mathbf{x}|\mathbf{x}_1)\|^2\right]\]

Why this works

The conditional FM loss has the same gradient as the marginal FM loss. This means we can train with cheap single-sample estimates, avoiding costly density evaluations. The neural network learns to point toward the data — a simple, stable regression objective.

The Flow Matching Sampler

Putting it all together — generation by ODE integration

Training summary

We train a neural network \(v_\theta(\mathbf{x}, t)\) to match the conditional vector field. Once trained, we sample by integrating the learned ODE forward from \(t=0\) to \(t=1\):

\[\frac{d\mathbf{x}}{dt} = v_\theta(\mathbf{x}, t), \qquad \mathbf{x}(0) \sim \mathcal{N}(0, I)\]

Any numerical ODE solver works — Euler, RK4, or adaptive solvers. The result is a sample from the learned distribution \(\hat{p}_1 \approx p_1\).

Complete algorithm

Training Sample \(t \sim U[0,1]\), \(\mathbf{x}_1 \sim q\), \(\mathbf{x}_0 \sim \mathcal{N}(0,I)\). Compute \(\mathbf{x}_t = (1-(1-\sigma_{\min})t)\mathbf{x}_0 + t\mathbf{x}_1\). Regress \(v_\theta(\mathbf{x}_t, t)\) onto \(u_t = \mathbf{x}_1 - (1-\sigma_{\min})\mathbf{x}_0\).

Inference Sample \(\mathbf{x}_0 \sim \mathcal{N}(0,I)\). Integrate \(d\mathbf{x} = v_\theta(\mathbf{x},t)dt\) from \(t=0\) to \(t=1\) using Euler with \(N\) steps.
